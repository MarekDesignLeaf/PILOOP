# PILOOP Living Heart

Source code for the PILOOP heart and character simulator. The heart life preview is implemented in `app/heart-life-preview.tsx`, `lib/heart-preview.ts`, `lib/heartbeat.ts`, and `hooks/use-heartbeat.ts`.

This application uses Node.js 22 or newer. Install with `npm ci`, then run `npm run dev`. The project includes Cloudflare Sites configuration and a database for character state. The heart life preview itself is a separate demonstration and does not modify a character's lifecycle.
